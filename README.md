# Pen Store
1. สร้าง repo ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมด (รวมโฟลเดอร์ .github)
2. แท็บ Actions -> Build Pen Store -> รอเสร็จ -> โหลด Artifact `PenStore-exe` ได้ PenStore.exe
ทดสอบในเครื่อง: `npm install && npm start` (กด F12 เพื่อดู error)

## โหลดเกม
เปิดเกม -> เลือกไฟล์ [WIN] -> DOWNLOAD แอปเปิดเว็บเบื้องหลัง กดโหลดให้ แสดง % แตกไฟล์ (zip/7z/tar) แล้วกด PLAY เปิด exe
ไฟล์เกม/save/ไลบรารีเก็บในโฟลเดอร์ `PenStore-Data` ข้าง PenStore.exe
