# Pen Store
1. สร้าง repo ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมด (รวมโฟลเดอร์ .github)
2. แท็บ Actions -> Build Pen Store -> รอเสร็จ -> โหลด Artifact `PenStore-exe` ได้ PenStore.exe
ทดสอบในเครื่อง: `npm install && npm start`

## เกมแบบโหลดไฟล์ (exe/zip)
เลือกไฟล์ Windows ในหน้าเกม -> INSTALL (เก็บลงเครื่อง) หรือ TEMP (ลบหลังปิดเกม/ปิดแอป) แอปแตก zip แล้วเปิด exe ให้อัตโนมัติ
เกมที่ต้องซื้อ/มีหน้าดาวน์โหลดพิเศษ จะเปิดหน้าต่างให้กดดาวน์โหลดเอง แล้วแอปจะรับไฟล์ต่อให้
