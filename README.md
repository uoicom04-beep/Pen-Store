# Pen Store
1. สร้าง repo ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมด (รวมโฟลเดอร์ .github)
2. แท็บ Actions -> Build Pen Store -> รอเสร็จ -> โหลด Artifact `PenStore-exe` ได้ PenStore.exe
ทดสอบในเครื่อง: `npm install && npm start` (กด F12 ดู error)

ค้นหา: พิมพ์ชื่อเกม Enter | `#horror` = ค้นตามแท็ก
ไฟล์เกม/save/ไลบรารี เก็บในโฟลเดอร์ `PenStore-Data` ข้าง PenStore.exe
